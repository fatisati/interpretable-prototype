  [VERIFIED FROM CODE, 2026-09-14 -- your reading is CORRECT.]
  This is `lambda_proto_usage`. The best run uses proto_usage_mode='ema'
  (scproto.py:1516-1525). What it actually computes:

      strongest_cell[p] = max over cells of assign[cell, p]   # MAX, not a sum
      usage_loss        = -log( EMA(strongest_cell) ).mean() / (1 - alpha)

  So it asks exactly one question: "does every prototype have at LEAST ONE cell
  that strongly belongs to it?" -- which is what you guessed.

  Two consequences worth remembering:

  1. It SAYS NOTHING ABOUT SIZE. A prototype with 1 confident cell and a
     prototype with 5000 cells both satisfy it equally.
  2. It SATURATES. Once strongest_cell is near 1, -log(strongest_cell) is near 0
     and there is no gradient left. It stops one prototype from dying; it does
     not shape the size distribution at all.

  WHAT THIS DOES *NOT* SETTLE: which force actually equalizes metacell sizes.
  The code argument above only shows the usage loss has no DIRECT headcount term.
  It can still change sizes INDIRECTLY, and no run so far separates it from gamma,
  so nothing here is attributed. See context/EXPERIMENTS.md for the measurements and
  the one run that would settle it.

  Note there is a third mode, proto_usage_mode='nk', which uses the SUM
  (n_k = total soft cells in prototype p) instead of the max:
      usage_loss = log(1 + 1/n_k).mean()
  That one does see headcount -- but it also saturates fast: at n_k=292 it is
  0.0034, essentially zero. So it lifts a nearly-empty prototype and then goes
  quiet. Still not a uniformity prior.
  A real uniformity prior does exist in the code (`lambda_collapse`, DMoN's
  collapse regularization) but it is OFF (0.0) in every run so far.

================================================================================
OPEN QUESTION (2026-09-14): is the LOSS at fault, or the ENCODER?
================================================================================

THE SETUP. On s28nsc / bk02 / K=200, against SEACells:
    DGE pearson_r   0.839 vs 0.849   TIED (all paired tests p >= 0.19)
    coverage        14    vs 19      BEHIND
    joint purity    0.431 vs 0.504   BEHIND
The joint-purity gap is ENTIRELY niche purity:
    cell type purity   scProto 0.849  vs SEACells 0.823   <- WE WIN
    niche purity       scProto 0.488  vs SEACells 0.591   <- WE LOSE
Empirically joint ~= 1.04 * ct * niche for both methods, so if we matched SEACells'
niche purity while keeping our own cell-type purity we would score 0.522 > 0.504,
i.e. WIN outright. Target: niche purity 0.488 -> 0.571.

ALSO CHECKED: are SEACells' 5 extra states spurious (over-split on position with no
real expression signal)? NO. Their mean pearson_r is 0.850 vs 0.855 for the 14 shared
states, their tpr is 0.95-1.00, and each has 25-87 genes significantly DE in the REAL
SINGLE CELLS. They are real states that scProto simply misses. scProto found zero
states SEACells did not -- it is a strict subset.

--------------------------------------------------------------------------------
MY (FATEMEH'S) ARGUMENT -- the loss is at fault
--------------------------------------------------------------------------------
If a state has 74 genes differentially expressed in the single cells, then the signal
IS in the gene expression matrix. scProto's encoder reads the gene expression matrix.
So the information is available to scProto. Failing to use it is a MODEL/LOSS failure,
not a missing-input problem. If the loss were doing its job, scProto should capture it.

--------------------------------------------------------------------------------
CLAUDE'S COUNTER-ARGUMENT -- the encoder is at fault
--------------------------------------------------------------------------------
Spatial info reaches the assignment ONLY as a gradient from a regularizer, never as an
input. `affinity_type` is consumed only in graph_generator.py; it builds the affinity
graph and never touches the encoder. Assignment is softmax(z . prototype) with z from a
CVAE trained to reconstruct expression. 8 dims for 18 cell types leaves little room for
within-cell-type niche substructure, and reconstruction spends dimensions on the largest
variance directions = cell type. Suggestive (not proof): our cell-type purity BEATS
SEACells while niche purity badly trails -- the signature of capacity spent on cell type.

CONCEDED: the evidence Claude first gave for this was CIRCULAR. "Niche purity does not
respond to 4x more spatial weight in the graph (0.491 -> 0.496)" is equally consistent
with a broken loss, which also would not respond to a better graph. That result does NOT
discriminate between the two explanations.

--------------------------------------------------------------------------------
THE UNVERIFIED PREMISE IN BOTH ARGUMENTS
--------------------------------------------------------------------------------
"DE genes exist" proves the GROUP MEANS differ. It does NOT prove individual CELLS are
separable. With ~74 significant genes out of 960 at CosMx sparsity, per-cell niche
classification can sit near chance while the pseudobulk difference is highly significant.
If niche is not separable AT THE CELL LEVEL, then no loss can cluster on it and the whole
debate is moot.

--------------------------------------------------------------------------------
THE TEST THAT SETTLES IT (cheap, no training, no Modal)
--------------------------------------------------------------------------------
For each cell type separately, predict the NICHE label from a representation
(kNN or logistic regression, balanced, compared against the majority-class baseline):

    1. raw expression / PCA      upper bound -- is it there at the cell level AT ALL?
    2. BANKSY bk02 embedding     what SEACells actually partitions
    3. scProto's 8-d latent z    what scProto actually partitions

READING THE OUTCOME:
    z ~= expression   signal survives the encoder, the metacells throw it away
                      -> THE LOSS IS AT FAULT (Fatemeh right). Prime suspect is the
                         off-diagonal term: it averages 39,800 near-zero prototype
                         pairs, contributes ~0.005, and so exerts no pressure to keep
                         distinct states apart.
    z << expression   the encoder drops it -> no loss change can recover it
                      -> THE ENCODER IS AT FAULT (Claude right). Then it is capacity
                         or objective: raise latent_dims, or feed the spatial
                         embedding to the encoder as an INPUT rather than a penalty.
    expression ~= chance
                      the DE signal is real at group level but not at cell level
                      -> NEITHER is at fault; the coverage target itself needs rethinking.

================================================================================
HOW THE DGE GROUND TRUTH IS DEFINED -- "1 niche vs REST OF NICHES, WITHIN ONE CELL
TYPE" -- and confirmation the code really does that (checked 2026-09-14)
================================================================================

This is the definition the whole "we find more cell states" claim rests on, so it is
worth stating exactly once and never re-deriving it.

GROUND TRUTH SIDE (real single cells) -- niche_dge.py:82-110, compute_ground_truth:
    for each cell_type ct:
        take ONLY the cells of that cell type            <- ct_ad = adata[obs[ct]==ct]
        for each niche n inside that cell type:
            pos  = cells of ct that are in niche n
            ctrl = cells of ct that are in ANY OTHER niche
            rank_genes_groups(pos vs ctrl, method='wilcoxon', reference='ctrl')
    gates: >=5 cells in pos, >=20 in ctrl, niche 'Excluded' dropped.
    runs on log-normalized adata.X.

METACELL SIDE (measured) -- niche_dge.py:206-213, _pair_groups:
    mcs  = metacells whose MAJORITY cell type == ct
    pos  = those whose MAJORITY niche == n
    ctrl = those whose MAJORITY niche != n           (same cell type)
    gates: >=2 metacells in pos, >=2 in ctrl (MIN_POS_MC / MIN_CTRL_MC).

VERDICT: CORRECT. Both sides are "this niche vs the other niches, inside one cell
type." The comparison is structurally matched -- we are not accidentally comparing
across cell types, and the control group is the right one.

TWO THINGS TO KNOW ABOUT IT, though:

(1) The metacell side uses MAJORITY-VOTE labels (majority_label_metacells), while the
    ground truth uses each cell's TRUE labels. So a method with low joint purity puts
    partly-wrong cells in its 'pos' group. MEASURED: this coupling is WEAK --
    spearman(niche_purity, pearson_r) is +0.08 for both methods across shared states.
    So purity contamination is NOT what is depressing DGE. The two metrics are
    effectively independent here.

(2) pearson_r is computed ONLY on genes already significant in the single cells
    (pvals_adj<0.05, top 100 by |logFC|). See the METRICS REFERENCE in context/
    current.txt. It is a REPRODUCTION test, not a DISCOVERY test.

--------------------------------------------------------------------------------
THE CONSEQUENCE NOBODY HAD NOTICED: MIN_POS_MC=2 IS A HARD SIZE FLOOR
--------------------------------------------------------------------------------
A state is only COUNTED as found if at least 2 metacells MAJORITY-belong to it. With
K=200 on 58,423 cells the mean metacell size is pinned at N/K = 292 by arithmetic, so
a state needs roughly 2 x 292 = 584 cells before it can possibly own 2 metacells.

Check against the 5 states SEACells found and scProto missed:

    Cytotoxic T cells    | Tumor surface         537 cells  = 1.8 scProto metacells
    Fibroblasts          | Alveolar spaces       415 cells  = 1.4
    Macrophages          | Airways               310 cells  = 1.1
    Regulatory T cells   | Desmoplastic stroma   280 cells  = 1.0
    Vascular endothelium | Alveolar spaces       276 cells  = 0.9

    ALL FIVE are below the 584-cell floor.
    The 14 states BOTH methods found have >=865 cells (median 1826).
    -> PERFECT SEPARATION at exactly the size floor.

SEACells clears the floor because its sizes are SKEWED, not uniform: median 258, and
for precisely these missed states it produced metacells of 154-303 cells (2-3 of them).
scProto's sizes sit at median 296, tightly around the mean -- so a 276-cell state can
at best majority-own ONE metacell, and is therefore INVISIBLE to the coverage metric.

STRUCTURAL CEILING on coverage, if metacells stay uniform at size N/K
(of the 64 states that have enough DE signal to be testable at all):

        K      mean mc size    floor=2*size    states reachable
      200          292             584                20
      400          146             292                32
      800           73             146                49
     1600           37              73                54

HOW TO READ THIS -- the coverage gap splits into two separate problems:
  * 14 -> 20 IS REACHABLE AT K=200 TODAY. Uniform 292-cell metacells already permit 20
    states; we get 14. Those 6 are a LOSS problem (prototype placement), and 20 > 19,
    so BEATING SEACELLS ON COVERAGE IS POSSIBLE WITHOUT CHANGING K.
  * beyond 20 is NOT reachable at K=200 under uniform sizing. That needs either a
    larger K or a loss that tolerates UNEVEN metacell sizes (which is what SEACells
    effectively has). Which knob buys that unevenness is NOT established -- see
    context/EXPERIMENTS.md.

This sits alongside, and does not replace, the section 9 finding in context/
decisions.md: the prototype assignment throws away 40% of the niche signal that the
latent z demonstrably carries. Both are true -- placement quality explains the niche
purity gap, and the size floor explains part of the coverage gap.
